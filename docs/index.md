# Minecraft Guides

Поэтапные гайды по модам Minecraft: какие машины ставить, сколько, на чём они
работают и сколько времени уходит на этап. Числа посчитаны по рецептам из
файлов мода, а не взяты из памяти.

## Modern Industrialization

Путь от начала мода до квантовой брони. Названия машин и предметов —
английские, как в игре: их удобно копировать в поиск рецептов.
